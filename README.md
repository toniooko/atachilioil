# ATÁ Website — Flat Production Build

All files live at the root level. Upload them all to your GitHub repo's root, or drag this folder into Netlify.

## Deploy on Netlify

1. Drag this entire folder onto Netlify's "deploy manually" drop zone, OR
2. Push these files to the **root** of your GitHub repo and connect Netlify
3. Publish directory: leave blank (or `/`)

## File list

- `index.html` — main page
- `styles.css` — all styles
- `tweaks-panel.js`, `store.js`, `components.js`, `sections.js`, `cart.js`, `cms.js`, `app.js` — app
- `logo.png`, `hero-bottle.png`, `single-bottle.png`, `double-bundle.png`, `triple-bundle.png`, `heritage.jpg` — images
- `_redirects` — Netlify routing fallback

## Editing content

Click the red ✎ EDIT button (bottom-right of site), password `ata-admin`.
